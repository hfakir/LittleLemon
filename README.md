# Little Lemon iOS App

Capstone project for the Meta iOS Developer Professional Certificate on Coursera.

![Uploading app-demo.gif…]()



## Features
- **Onboarding Screen:** User registration with persistent local storage.
- **Home Screen:** Interactive menu list with search and category filters.
- **User Profile:** View and update personal details, manage email notifications, and log out functionality.
- **Core Data & Local Persistence:** SQLite integration with JSON menu parsing and hardcoded fallbacks.
